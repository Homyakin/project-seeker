# Материалы проекта 15.4.3

Основной [результат шага](../raid-redesign-step-15-4-3-participant-adjustment.md). Это исследовательский помощник вне игрового кода, не включённый выпуск и не закрытие шага 15.

## Основа и неизменность

Используется текущая публичная основа 15.2: [203 входных файла](../raid-redesign-step-15-2-evidence/inputs.sha256), [архив исходников](../raid-redesign-step-15-2-evidence/sources.tar.gz), SHA архива `88cb5b11036788a0f211f417d2f2cde81c2268aed373afa31c447686c38cf842`. Чувствительные профили, полная папка сборки, зависимости и база не архивировались. Проверки их не требуют. Для повторного исполнения боёв нужны отдельно JDK и зависимости из прежнего общедоступного описания среды; никакого запуска приложения или Telegram нет.

`source-basis.sha256` и `class-basis.sha256` фиксируют использованную локальную основу, а `source-archive-preflight.json`/`source-archive-postrun.json` — её соответствие сохранённому архиву до/после разведки. Это исторические квитанции с исходными абсолютными путями. Исторические исследования и результаты не заменены.

## Разведка

- [Политика до исходов](screen-policy.json): ровно 11 200 исполнений, 76 условий, 224 сочетания правил, по 25 зеркальных пар.
- [Исходник помощника](Step1543HeterogeneityProbe.java), [описание исполнения](controls.md), `source-inputs/` с точными прежними входами 15.3.
- `frozen-preparation/`: подготовленные до боёв входы, 475 записей начальных значений, 224 первых снимка, формулы и точная копия исходника/политики.
- [Заморозка](prebattle-freeze.sha256), [контрольные записи](control-record.sha256), [независимое разрешение запуска](independent-preflight-ack.json). Проверка подготовки не выдаётся за проверку исходов.
- `pilot/`: исходный `battles.jsonl.gz` без перепаковки, полный перечень входов, начальных значений и [сводка](pilot/summary.json). SHA сжатого потока `90305838c4e6f8b28d37b574141dc3f5d3b5aef06694a9e22b2d7c02d0a08f21`.
- [Полный независимый аудит](method/screen-validation-final.json): 7 595 813 утверждений, все 11 200 исполнений, 448 полных журналов с отдельными следами исполнения; 1800 исполнений одиночек/однородных команд сохранили точные исходы, статистику и хеши. Ранняя [квитанция аудита](method/screen-validation.json) сохранена отдельно. [Независимая рецензия](pilot-review/REVIEW-RU.md) и её [самостоятельный пересчёт](pilot-review/review.json) — второй взгляд на тот же поток, не дополнительная выборка.
- `analysis/` и `method/`: исходная алгебра, численные проверки и ограничения модели. Скрипт `analysis/assessment.cjs` — исторический расчёт по первоначальным путям `/tmp`; его результат сохранён, это не универсальный переносимый запускатель боёв.

Строки потока содержат исходные и конечные характеристики, реальные составы/предметы, оценки и целевые значения, исходы, статистику, хеши журналов. Полные события и отдельные `traceEvents` сохранены у первой пары каждого сочетания с правилом и обоих порядков сторон. Число событий не равно числу действий. Незавершение не подменяется поражением.

Переносимый независимый пересчёт разведки без записи файлов и без новых боёв, из корня репозитория:

```sh

node documentation/raid-redesign-step-15-4-3-evidence/method/validate-heterogeneity.cjs documentation/raid-redesign-step-15-4-3-evidence raw
```

`pilot-review/review.cjs` — также сохранённый исходный скрипт рецензента с историческими путями; для переносимого пересчёта предназначена отдельная версия `pilot-result-checker.cjs`. Новая версия не подменяет первоначальную квитанцию рецензии.
