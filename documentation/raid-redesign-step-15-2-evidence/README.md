- `collect-test-summary.cjs` — повторяемый сборщик чисел из отдельных отчётов Surefire и отметок окончательной сборки. Он не копирует свойства JVM, полные тестовые журналы или настройки приложения. Контрольная сумма полного журнала сборки записана в результате, сам журнал не включён в пакет.
- `sources.tar.gz` — 203 выбранных открытых файла поверх исходного состояния репозитория `bd142e61a0aa2fc0e1b2117164ab4bc6fac29469`. Это снимок нужной основы и изменений, **не полный репозиторий**. Контрольная сумма: `88cb5b11036788a0f211f417d2f2cde81c2268aed373afa31c447686c38cf842`.
- `selected-inputs.txt`, `inputs.sha256`, `source-change-audit.json` — точный состав и сравнение с основой шага 15: 190 прежних файлов не изменились, восемь обновлены, пять добавлены. Игнорируемая локальная конфигурация, сборочные файлы и постороннее изменение `InMemoryLockServiceTest` исключены. Сборка видела последнее изменение, но эта часть его не редактировала.

Среда: JDK 25.0.1 с целью компиляции 24, Maven 3.9.12, явный агент `Mockito` 5.18.0. Проверки БД остаются условными: прежние 19 намеренных и 10 условных пропусков не объявляются успешно выполненными проверками.

Команда окончательной сборки из `game` в использованной среде:

```sh
env JAVA_HOME=/home/user/.jdks/axiomjdk-25.0.1 \
  JAVA_TOOL_OPTIONS=-javaagent:/home/user/.m2/repository/org/mockito/mockito-core/5.18.0/mockito-core-5.18.0.jar \
```

Рабочий снимок нельзя восстанавливать поверх чужих изменений без отдельного решения. Для повторения использовать новую временную копию указанной основы, наложить только перечисленные файлы и проверить `inputs.sha256`.

## Сверка с проектом и прежним генератором

`verification.tar.gz` содержит полный сравнительный результат и вспомогательные исходники вне рабочего модуля. Контрольная сумма: `4029edfc0e6b00079fc2e82c1e7cd9fcfc055c6223409e061229c5522b81af27`. Краткая сводка вынесена в `verification-summary.json`.

Основной агент независимо распаковал оба архива, проверил 203 исходных файла и все перечисленные внутренние контрольные суммы, заново выполнил оба сравнения и подтвердил неизменность производственных классов. Результат сохранён в `package-validation.json`.

Состав архива:

- `Step152StructuralProbe.java`, `compare.cjs`, `commands.sh`, `modern.json`, `comparison.json` — восстановление 90 полных входов из архива [15.1](../raid-redesign-step-15-1-evidence/README.md). При прямом вызове и через настоящий `RaidGenerator` все 90 наборов характеристик противников совпали точно; множители также совпали. Наибольшее относительное отличие оценки — около `10⁻¹⁵`, целочисленные свойства не изменились. Прототипные идентификаторы/инициатива исключены из этого сравнения: у прототипа был отдельный поток окончательного создания противников.
- `baseline-source/MyconidColonyGenerator.java`, `historical-current.json`, `historical-baseline.json` — 72 условия трёх прежних версий противников. Два процесса различались только подставленным классом генератора. Оба файла побайтно равны, SHA-256 каждого: `5cc39203e252e06828c6f4fbe9593f55fe36887d08ccdcf549176ab4b0726658`. Здесь сравниваются и идентификаторы, и начальная инициатива. Игроки в обоих процессах подготовлены одинаково с V3.
- `failed-attempt.json`, исходник первоначального помощника и два первоначальных журнала — исключённая первая попытка исторической сверки. Она не дала проверочного результата: помощник попытался применить недоступный старой версии `GUARD` к игроку. В исправленном опыте версия подготовленных игроков одинакова, а выбирается только проверяемая версия противников. Рабочий генератор для исправления опыта не менялся.
- `Step152ReplayProbe.java`, `compare-replay.cjs`, `replay-commands.sh`, `replay-a/`, `replay-b/`, `replay-receipt.json` — два отдельных процесса настоящего `Battle.process`: 12 условий × два порядка сторон, 24 боя в исходном прогоне и те же 24 при повторе. Ни одного незавершения.
- `production-classes.sha256` — выбранные производственные классы после окончательной сборки; их неизменность после всех вспомогательных прогонов проверена. `artifacts.sha256` проверяет определённые внутренние файлы архива.

Повтор боя сравнивает все сохранённые значения, начальное состояние и контрольные суммы журналов действий/трассировки. Канонический полный поток побайтно совпал, SHA-256: `299c33d6ca6cd62f0a071fb403af5fcd654020f15483e06080dbc2c3d61de5d4`. Канонизация упорядочивает **только** элементы множеств `slots` и `availableOnSlots`, порядок которых при сериализации может отличаться между JVM. Другие массивы, события, значения и идентификаторы не переставляются и не удаляются. Исходные неканонические потоки сохранены оба; `rawByteExact=false` прямо указан в квитанции.

## Проверка пакета

Из корня репозитория:

```sh
sha256sum -c documentation/raid-redesign-step-15-2-evidence/inputs.sha256
verification_dir=$(mktemp -d /tmp/seeker-step15-2-review.XXXXXX)
tar -xzf documentation/raid-redesign-step-15-2-evidence/verification.tar.gz -C "$verification_dir"
(cd "$verification_dir" && sha256sum -c artifacts.sha256)
node "$verification_dir/compare.cjs" "$verification_dir"
node "$verification_dir/compare-replay.cjs" "$verification_dir"
```

Точные команды компиляции помощников и двух отдельных процессов находятся внутри архива. Для структурного сравнения нужны неизменённые входы `bounded-tail-results/` из пакета 15.1. Вспомогательные классы компилируются в отдельную временную папку, не в `game/target`; исторический класс подставляется только в одном отдельном процессе. Команды из использованной среды содержат временные пути, которые при повторении требуется заменить своими.

Внешний `artifacts.sha256` проверяет все файлы этого пакета, кроме самого списка. Исходные архивы шагов 13–15.1 не переписывались.

## Границы вывода

Модульные проверки, точное совпадение характеристик и повторяемость боя не доказывают приемлемую долю побед. Числа исходной разведки 15.1 не превращены в новый независимый замер. 24 повторённых боя — проверка воспроизведения, не 48 независимых наблюдений.

Полные журналы действий всех боёв здесь не сохраняются: сохранены начальные состояния, контрольные суммы журналов действий/трассировки, результаты и входы для повторения. Нужны отдельные новые подтверждения 15.3 у границ исходов, других сборок, эффектов и слабых наполнителей. Параметры пока исходные, рабочая конфигурация и БД не переключались, приёмка шага 15 не закрыта.
