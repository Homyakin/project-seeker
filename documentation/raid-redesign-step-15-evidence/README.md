# Свидетельства незавершённого шага 15

**Это не приёмка Колонии миконидов.** Подтверждён крупный вред от добавления обычного участника. Выпуск не включался, шаг 16 не начинался. [Причина остановки и выполненные изменения](../raid-redesign-step-15-myconid.md).

## Полностью сохранённые прогоны

| Каталог | Что проверяется | Условия × пары × стороны |
|---|---|---:|
| `runs/risk` | Неизменная тройка и она же плюс обычный Громила, уровень 25, средняя/сильная ступени | 4 × 500 × 2 = 4000 боёв |
| `runs/available-answers` | Доступные ответы слабым одиночному и переднему составам | 4 × 500 × 2 = 4000 боёв |
| `runs/live-causal` | Добавление обычного/живого слабого участника, заточка одного предмета, изменение одной редкости | 180 × 20 × 2 = 7200 боёв |

В этих каталогах сохранены `summary.json` и полный поток записей `battles.jsonl.gz`. Запись содержит полные входы, начальный снимок, исход, показатели действий и контрольные суммы журналов. Полные журналы действий основного прогона представлены контрольными суммами, не повторены в каждой записи.

В `validation/` — независимые проверки трёх сохранённых прогонов. `risk-replay.json` дополнительно подтверждает **полное совпадение повторных 4000 боёв в отдельном процессе Java после окончательной сборки**; распакованный поток имеет SHA256 `51433c4eb86b821f0f246e1d6066d724749a3ce1d8f812b9974a63292b21ff0a`. Повтор не добавляется к числу независимых наблюдений.

## Где сохранены только сводки

Десять широких, предварительных и отклонённых прогонов находятся в `summaries/`. Это **только сводки и контрольные суммы исходных полных потоков**, не полные наборы записей. В частности:

- `before` и `range` — сравнение первоначального состояния с дальностью `1…3` и единой численной поправкой;
- `candidate` — 390 условий, 15600 боёв;
- `curve` — дополнительные уровни 20/30/40;
- `normal-confirmation` — добавление обычного участника на уровне 10, где насыщение победами скрывает риск уровня 25;
- `guard-redistribution`, `initiative`, `initiative-screen` — **отклонённые** параметры, не оставленные в коде;
- `causal` и `causal-confirmation` содержат прежний ошибочный опыт с нулевым здоровьем и не используются как доказательство вреда живого слабого игрока.

`run-inventory.json` перечисляет каждый прогон, его параметры, исходный SHA256 и наличие полного потока в этом архиве. Временные исходные потоки при подготовке материалов не изменялись; их долговременное наличие не обещается. Для независимой проверки сводок без сохранённого потока требуется повторить соответствующий прогон из зафиксированных источников и параметров. Нельзя утверждать, что всё исследование полностью архивировано.

## Ошибочный опыт и диагностика

`invalid-dead/` сохраняет прежний исходник стенда, сводку и две неизменённые исходные записи первого парного опыта с одним мечом. В нём здоровье добавленного участника равно нулю. Это явно помеченный **невалидный опыт для вывода о новичке**, а не результат, переименованный задним числом. Текущий проверочный скрипт такой вариант отклоняет с `DEAD_APPEND_EXCLUDED`.

Исправленный слабый участник — обычный меч и шесть встроенных предметов V5, все `+0`, без модификаторов, семь разных ячеек и 840 здоровья. Именно он используется в `runs/live-causal`.

`diagnostic/` содержит показатели участников 160 диагностических боёв и полные журналы первых двух пар каждой из четырёх ячеек. Там используется **отклонённый** профиль Стража `105 атаки / 280 здоровья`; `status.json` явно указывает это ограничение. Нельзя переносить его конкретные показатели на восстановленный профиль `70 / 420` без нового измерения.

## Источники и сборка

`sources.tar.gz` содержит 198 явно выбранных общедоступных исходников под `source/`, список и их контрольные суммы. Основа проекта — `bd142e61a0aa2fc0e1b2117164ab4bc6fac29469` плюс сохранённые файлы. Это не полный независимый дистрибутив. Секретные настройки, рабочая БД, `target` и посторонняя проверка блокировок исключены.

`source/` рядом с архивом содержит снимки четырёх исследованных вариантов генератора и `MyconidMarginalProbe.java`. Текущий генератор побайтово совпадает с `range-source.java`; неудачные атака/здоровье и скорости сняты. Для воспроизведения старого варианта его источник нужно использовать **в отдельной копии проекта**, не подменять им текущий генератор рабочего репозитория.

`snapshot-metadata.json` описывает оставленные параметры и среду. `test-summary.json`: `mvn -o clean package`, **1616 проверок, 1587 успешных, 29 прежних/условных пропусков, ошибок нет, Checkstyle — 0**; все 46 новых точных проверок прошли. PostgreSQL не подключалась. Успех сборки не закрывает блок баланса.

## Проверка

Из корня репозитория, Node.js 24.22.1:

```sh
node documentation/raid-redesign-step-15-evidence/validate-myconids.cjs documentation/raid-redesign-step-15-evidence/runs/risk
node documentation/raid-redesign-step-15-evidence/validate-myconids.cjs documentation/raid-redesign-step-15-evidence/runs/available-answers
node documentation/raid-redesign-step-15-evidence/validate-myconids.cjs documentation/raid-redesign-step-15-evidence/runs/live-causal
sha256sum -c documentation/raid-redesign-step-15-evidence/inputs.sha256 --quiet
```

Суммы исходников проверяются относительно корня зафиксированной копии; после дальнейших изменений они закономерно разойдутся. Проверка `artifacts.sha256` выполняется из каталога этих материалов. `package-artifacts.sha256` — первоначальная сумма пакета до добавления итогового README и повторной проверки.

## Воспроизведение блокирующего результата

В отдельной проверенной копии источников собрать модуль; использовались JDK 25.0.1, цель компиляции 24 и Maven 3.9.12. При необходимости среды включить явный агент `Mockito`. Приложение, бот и БД для стенда не нужны.

```sh
cd game
mvn test-compile
mvn dependency:build-classpath -Dmdep.outputFile=/tmp/seeker-step15-classpath.txt
java -Xmx768m -Dmyconid.study.suite=causal -Dmyconid.study.pairs=500 \
  -Dmyconid.study.causalExtraLevels=25 -Dmyconid.study.causalGroupIds=27,33 \
  -Dmyconid.study.causalVariants=BASE,NORMAL_APPEND \
  -Dmyconid.study.seedOffset=300000000 -Dmyconid.study.phase=GUARD_RISK_077 \
  -cp "target/test-classes:target/classes:$(cat /tmp/seeker-step15-classpath.txt)" \
  ru.homyakin.seeker.game.battle.MyconidAdaptationStudy /tmp/seeker-step15-new-risk
```

Каталог результата должен отсутствовать до запуска. Затем из корня проекта:

```sh
node documentation/raid-redesign-step-15-evidence/validate-myconids.cjs \
  documentation/raid-redesign-step-15-evidence/runs/risk /tmp/seeker-step15-new-risk
```

Результат обязан совпасть целиком, включая контрольные суммы действий и сводку. Для других полностью сохранённых прогонов параметры находятся в их `summary.json`; источники случайности и правила номеров условий зафиксированы там же. Попытки сравнения разных параметров, фаз или источников не являются точным повтором.
