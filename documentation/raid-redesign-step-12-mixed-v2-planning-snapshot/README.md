# Снимок документов до смены целей баланса

Создан 2026-10-23 перед обновлением живого плана под допустимую мету и защиту от крупных перегибов. Файлы с окончанием `.snapshot` — точные побайтовые копии одноимённых документов из родительского каталога до этих правок. Это исторические тексты, а не действующие инструкции.

Шесть копий входят в замороженный перечень входов [второй проверки смешанных сборок](../raid-redesign-step-12-mixed-v2-inputs.sha256) с отпечатком `eff921f4204d281451dc0978a188db64e315be31e3a9d9fd47636ba15a254466`: план, отчёт приёмки, формулы умений, матрица сборок, каталог и расчёт развития. Дополнительно сохранено описание ролей шага 3; оно не входило в этот перечень.

Для восстановления старых входов скопировать нужную `.snapshot` в отдельную копию репозитория по исходному пути `documentation/<имя без .snapshot>`. Остальные файлы и точный набор путей берутся из прежнего перечня; он остаётся неизменным. Сам снимок не является новой приёмкой и не разрешает повторно использовать одноразовые корни.

Текущие решения: [политика баланса](../raid-redesign-balance-policy.md) и [поэтапный план](../raid-redesign-plan.md). Прежний итог: [успешная квитанция](../raid-redesign-step-12-mixed-v2-final-2026092701.receipt.properties).
