# Материалы шага 19.3

Дата: 2026-11-17. [Проект и границы](../raid-redesign-step-19-3-anomaly-difficulty.md).

Первоначальные материалы — повторное чтение неизменённых результатов 19.2 с отдельным выделением групп N3–5. После ответа пользователя зафиксированы [условия численной проверки](protocol.md): ориентир 80%, допустимо 75–90% основных команд; не всех сборок. Одиночки и двойки исключены из балансовых условий, их технические проверки не отменены. Численная проверка завершена; окончательные результаты приведены в разделе «Итог».

`existing-data.json` — независимые срезы исходных строк 19.2, привязанные к контрольным суммам исходного протокола, сырых строк и сводки. Основные, ритуальные, командные и бесплатные комплекты не объединяются ради средней доли побед. В дополнительных семействах прежняя выборка содержит N3/N5, но не N4.

`independent-project-review.md` — независимая проверка первоначального проекта до ответа о сложности; она сохраняется как история, не как заключение о принятом балансе или выполненной реализации. Исторические документы и материалы не переписываются.

`prepare-candidates.mjs` сохраняет исходники после 19.2 и компилирует семь отдельных вариантов настоящего генератора с одной V3-подстановкой коэффициента. `baseline-source/` и `pre-calibration-sources.tar.gz` — исходные снимки до этой калибровки; `candidate-generators/metadata.json` — рецепт и суммы, `candidate-generators.tar.gz` и `candidate-archive.json` — архив вариантов и его контрольная сумма. Рабочие исходники этим скриптом не изменяются. Старый/служебный классы каждого варианта загружаются вместе, остальные модели и бой общие.

## Численные фазы

`screen/` — первоначальное техническое планирование с ещё предварительной редакцией проверяющего, без боёв; сохранено, не используется для отбора. Окончательный протокол проб — `screen-v2/protocol.json`. `screen-v2/battles.jsonl.gz` и `summary.json` содержат все 20 160 боёв / 72 условия × семь значений. `screen-replay/` — 168 полных повторов. `screen-validation.json` — независимый пересчёт; `selection.json` — выбор `1.10`, 1118/1440 = 77,64% основной смеси, привязанный к суммам исходных данных. Никакие подтверждающие исходы в выбор не включены.

`confirm/` — отдельный протокол/23 040 боёв для исходного `0.92` и выбранного `1.10` на новой случайности. Выбранное значение использует производственный генератор; до боёв выполнены 5760 точных сравнений его генерации с изолированным вариантом. `confirm-replay/` — 144 заранее выбранных полных повтора. Дополнительные семейства и размеры раскрываются отдельно, включая неудачные контрвыборы.

Сборки: `clean-package-screen.log` — 2064 проверки до игровой правки; `clean-package-confirm.log` — 2144 после неё, включая 80 новых параметризованных проверок N1–5 и четырёх версий. Обе сборки успешны, 29 прежних/условных пропусков, ошибок и нарушений Checkstyle нет. `historical-compatibility.json` — 192 точных сравнения прежних версий после правки. Сервисные проверки проходят в полной сборке; реальные выплаты/БД не вызываются.

`screen-source-lock.sha256` и `confirm-source-lock.sha256` фиксируются до боёв своих фаз. Снимки `screen-input-sources.tar.gz` / `confirm-input-sources.tar.gz` и соответствующие `*-current-classes.tar.gz` сохраняют точные исходники и скомпилированные классы на тот момент. Подтверждающий снимок дополнительно включает новый `AnomalyV3DifficultyRatioTest.java`, которого не было в списке прежних тестов стенда. После разрешённой правки две рабочие версии файлов и класс закономерно отличаются от старых сумм SCREEN; его протокол и суммы не переписываются. Сохранённый `screen-source-validation-before-patch.log` подтверждает проверку всех прежних входов до изменения.

## Повторение

Все команды стенда выполняются из корня репозитория. `CP` содержит `game/target/test-classes`, `game/target/classes` и тестовые зависимости; сборка модуля — из `game`, `mvn -o -B -ntp clean package`. Использован JDK 25.0.1 с целью 24 и явный агент Mockito. Приложение, Telegram и PostgreSQL не запускаются.

```sh
java -Xmx2g -cp "$CP" ru.homyakin.seeker.game.battle.Step193AnomalyDifficultyStudy \
  plan SCREEN NEW_RUN candidate-generators
java -Xmx2g -cp "$CP" ru.homyakin.seeker.game.battle.Step193AnomalyDifficultyStudy \
  run SCREEN SAME_RUN candidate-generators
java -Xmx2g -cp "$CP" ru.homyakin.seeker.game.battle.Step193AnomalyDifficultyStudy \
  replay SCREEN SAME_RUN NEW_REPLAY candidate-generators
node documentation/raid-redesign-step-19-3-evidence/validate-study.mjs \
  SAME_RUN NEW_REPLAY NEW_VALIDATION_JSON
```

В примере `candidate-generators` заменяется полным путём к сохранённому каталогу вариантов. Для `CONFIRM` после каталога добавляется путь к неизменённому `selection.json`. Есть отдельный режим проверяющего `RUN --inputs-only NEW_REPORT`, который проверяет входы до боёв, но не выдаётся за пересчёт исходов. Все выходные пути должны быть новыми.

Точное повторение старого SCREEN требует его отдельного снимка исходников/классов, а не нынешних V3-источников после изменения `C`. Для новой копии опыта сначала создаётся новый протокол; старый не редактируется под рабочую директорию. `prepare-candidates.mjs` намеренно откажется заново снимать нынешний выбранный генератор как якобы исходный `0.92`: использовать сохранённые варианты либо отдельно восстановленный архивный снимок, не перезаписывая рабочие файлы.

`previous-artifacts-validation.json` подтверждает неизменность 15 прежних наборов материалов / 774 файлов. Это проверка сохранённых материалов, не обещание совпадения старых сумм нынешних исходников после разрешённой правки. Реальные выплаты, надёжность завершения и выпуск остаются за пределами 19.3.

## Итог

Обе фазы, независимые пересчёты и 312 полных повторов завершены успешно. `confirm-validation.json`: технические проверки и основная цель подтверждены; выбранные `1.10` дали **4544/5760 = 78,89%**, исходные `0.92` — 5531/5760 = 96,02%. Консервативный интервал по зеркальным парам — 76,36–81,42%. Всего 43 200 матричных боёв, без ничьих/незавершения, максимум подтверждения 81 такт.

Заключительные независимые [технический](independent-review-technical.md) и [балансовый](independent-review-balance.md) разборы выполнены после последней игровой правки. Дополнительные направления 81,90%, бесплатные 18,85%, отдельный тяжёлый контрвыбор командного против Бури 2,5%; это не приёмка одинаковой доступности всех комплектов. [Полный итог](../raid-redesign-step-19-3-anomaly-difficulty.md).

`inputs.sha256` фиксирует окончательные входы подтверждения; `artifacts.sha256` — сохранённые материалы и итоговый отчёт, без изменяемого общего плана и самого манифеста. Файлы журналов могут попадать под общие правила игнорирования Git; при будущей отдельной команде коммита их нужно добавлять явно в пределах этого каталога. Коммит и отправка здесь не выполнялись.
