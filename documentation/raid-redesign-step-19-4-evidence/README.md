# Материалы 19.4

[Итог](../raid-redesign-step-19-4-anomaly-completion.md), [условия до правок](protocol.md), [устройство стенда и ограничения](postgres-harness.md).

Доказательства исходного завершения:

- `baseline-completion-v5.log` / `.jsonl`: 77 случаев, 2 проверки исправления пропущены; настоящие исходные частичные записи, повторы и устаревшие снимки. `baseline-completion-v5-sources.tar.gz` сохраняет исходники основной проверки; в DAO объединения уже внесена отдельная подтверждённая правка, этот метод основная исходная матрица не вызывает.
- `baseline-postgres-v4.log`: действительное воспроизведение неисправностей объединения, 14 случаев (5 отказов утверждений, 3 ошибки, 6 успешных). Основной класс в этом же запуске ещё имел неверную фикстуру значка.
- `baseline-sources-v2.tar.gz`: завершённый снимок исходного кода до любых игровых правок 19.4. `baseline-sources.tar.gz` — предыдущая попытка с ошибочно указанным отсутствующим путём; сохранена, но не является опорным снимком.
- `baseline-main-classes.tar.gz` и `baseline-completion-v5-classes.tar.gz`: основные классы v5 и классы проверок; локальный игнорируемый конфиг исключён. Это состояние основной исходной матрицы, **не** неизменённый DAO объединения. Исходный DAO имеется в снимке исходников v2.

Неудачные подготовительные попытки сохранены отдельно: `baseline-completion.log` — ограничение локальных сетевых сокетов; `baseline-postgres-v2.log` и `baseline-completion-v2.jsonl` — неверные начальные фикстуры; `baseline-merge-v3.log` — отсутствующий обязательный перевод значка; `baseline-merge-v4.log` — прерванный запуск из-за координации Maven. Их нельзя выдавать за полную успешную матрицу или всеобщую неисправность игрового кода. Частичный `baseline-completion-v4.jsonl` относится к запуску v4, а не к окончательной исходной матрице.

После исправления:

- `targeted-final.log`, `final-completion.jsonl`: 343 затронутые проверки, из них 98 PostgreSQL; 89 строк наблюдений основного класса.
- `clean-package.log`, `clean-completion.jsonl`: отдельная полная чистая сборка и повтор PostgreSQL-матрицы (итог в основном отчёте).
- `validate-evidence.mjs`, `validation.json` / `.log` и `validation-clean.json` / `.log`: отдельный пересчёт числа сценариев, точных валют/статусов, откатов, повторов и наблюдаемого ожидания блокировки. Повтор не увеличивает независимую выборку баланса.
- `inputs.sha256`: открытые входные исходники и ресурсы; игнорируемый локальный конфиг не включён. `artifacts.sha256`: окончательные материалы этого шага, без самоссылки и живого общего плана.
- `lifecycle-audit.md`, `merge-lock-review.md`: предварительные тематические разборы; заключительные независимые разборы сохраняются отдельно.
- `previous-artifacts-validation.json`: 16 прежних наборов, 849 файлов, несовпадений нет. Исторические списки входов не проверялись против изменённого рабочего кода вместо сохранённых исходников.

Только новый временный контейнер PostgreSQL16, явный адрес `127.0.0.1:32768/seeker_anomaly_194`, случайные изолированные схемы и настоящие миграции. Никаких существующих томов, рабочей `seeker`, учётных данных Telegram или запуска бота. После проверок удаляется только созданный здесь временный контейнер с его тестовыми данными; состояние очистки фиксируется отдельно.
